## 统一使用规则

1. 先在顶层参数中把 `CLK_FREQ_HZ` 改为真实输入时钟，再设置 SPI/I²C 频率、采样周期和器件地址。
2. `sys_rst_n` 均为异步低有效复位。采样顶层在 `sample_valid=1` 的那个时钟周期输出新数据。
3. I²C SCL/SDA 按开漏设计，必须有外部上拉。不支持多主机仲裁或时钟拉伸。
4. 本目录不包含具体 FPGA 型号的管脚/XDC 约束。必须根据原理图添加 I/O 电平、管脚、时钟和输入/输出延迟约束。

每个子目录的 `readme.md` 详细列出了顶层端口、参数修改方法和硬件注意事项。
