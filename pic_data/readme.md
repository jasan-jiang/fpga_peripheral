# 摄像头图像 UDP 传输

本目录按传感器分为 `ov5640` 和 `ov7725`。两者都将 8-bit 摄像头字节流跨时钟写入 FIFO，按图像行拆成 UDP 包，并通过收到的单字节 UDP 命令启停传输。

| 子目录 | 差异 |
|---|---|
| `ov7725` | SCCB/I²C 默认地址 `7'h21`，8-bit 寄存器地址，顶层带 `cam_sgm_ctrl` |
| `ov5640` | 默认地址 `7'h3c`，16-bit 寄存器地址，可配置分辨率/总时序，顶层带 `cam_pwdn` |

每个子目录的 `readme.md` 描述顶层端口、网络参数、图像包格式和更换传感器时的修改点。

## 公共依赖

两个顶层都不是仅用当前子目录三个 `.v` 就能完整编译的独立工程。需要：

- `eth_ctrl`、`gmii_to_rgmii`、`arp`、`udp` 目录的 RTL；
- 与目标摄像头对应的 `i2c_ov*_rgb565_cfg` 寄存器表模块；
- 兼容相应端口的 `i2c_dri`；
- `clk_wiz_0` 和 `async_fifo_2048x8b` Vivado IP。

仓库当前没有收录摄像头寄存器表和上述两个 IP 的生成文件，集成时需从原工程加入或重新生成。
